# NotePi — Plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam caixas de seleção (`- [ ]`) para acompanhar o progresso.

**Objetivo:** construir o NotePi, um app web pessoal de anotações que roda num Raspberry Pi 3B e cruza notas por busca de texto, tags e versículos bíblicos.

**Arquitetura:** FastAPI renderiza páginas HTML (Jinja2) com um pouco de HTMX; os dados ficam num único arquivo SQLite com busca FTS5. A lógica fica em módulos Python pequenos e puros (`versiculos`, `tags`, `notas`, `busca`, `backup`), testados sem servidor; a camada web só chama esses módulos. No Pi, o systemd mantém o app e o backup diário; o Tailscale faz o acesso externo.

**Tecnologias:** Python ≥ 3.11, FastAPI, Uvicorn, Jinja2, python-multipart, markdown-it-py, SQLite (FTS5, WAL), HTMX 1.9.12, pytest, httpx.

**Especificação:** `docs/superpowers/specs/2026-11-10-notepi-design.md` (leia junto com este plano).

**Situação do código:** todo o código deste plano já foi escrito e testado num protótipo em 2026-11-10 (93 testes passando no Windows com Python 3.13, e um teste manual no navegador: prévia de versículos, rascunho, envio após reconexão e conflito). O plano reproduz esse código passo a passo, com TDD.

## Restrições globais

- Python **≥ 3.11** (o Raspberry Pi OS atual traz 3.11 ou mais novo).
- O servidor é um **Raspberry Pi 3B com 1 GB de RAM e cartão SD**: 1 worker do Uvicorn, sem dependências compiladas pesadas.
- O Uvicorn escuta só em `127.0.0.1:8000`; quem expõe o app é o `tailscale serve`.
- O SQLite usa `journal_mode=WAL` e `synchronous=NORMAL`; datas são texto ISO 8601 em UTC com microssegundos (`db.agora()`).
- Áreas válidas (exatamente): `biblia`, `tecnologia`, `financas`, `casa_obra`, `pintura`, `geral`.
- Modelos válidos (exatamente): `culto`, `guia_requisitos`.
- Forma canônica da tag de versículo: nome completo do livro + `cap` ou `cap:v` ou `cap:v1-v2` (ex.: `Romanos 12:1-2`).
- `Jó` (com acento) é o livro 18; `Jo` (sem acento) é sempre João (livro 43).
- O HTML digitado nas notas **nunca** é executado: markdown-it com `html=False`; trechos de busca passam por `markupsafe.escape`.
- Todo texto da interface é em português do Brasil, com acentos.
- **Git:** a pasta ainda não é um repositório. Antes do primeiro `git init` e do primeiro commit, pergunte ao Deividi; depois disso, siga os passos de commit de cada tarefa.
- Comandos de teste estão em PowerShell (Windows). No Linux/Pi, troque `.venv\Scripts\python` por `.venv/bin/python`.

````python
"""Funções pequenas de texto usadas em vários módulos."""

from __future__ import annotations

import re
import unicodedata


def remover_acentos(texto: str) -> str:
    """'Hermenêutica' -> 'Hermeneutica'."""
    decomposto = unicodedata.normalize("NFD", texto)
    return "".join(c for c in decomposto if unicodedata.category(c) != "Mn")


def slug(texto: str, maximo: int = 50) -> str:
    """'Pincel para parede!' -> 'pincel-para-parede'. Nunca devolve vazio."""
    base = re.sub(r"[^a-z0-9]+", "-", remover_acentos(texto).lower()).strip("-")
    return base[:maximo].rstrip("-") or "nota"
````

````python
"""Conexão com o SQLite, ajustes (PRAGMAs) e migrações do esquema."""

from __future__ import annotations

import sqlite3
from datetime import datetime, timezone
from pathlib import Path

VERSAO_ESQUEMA = 1

_MIGRACOES: dict[int, str] = {
    1: """
CREATE TABLE notas (
  id          INTEGER PRIMARY KEY,
  titulo      TEXT NOT NULL,
  conteudo    TEXT NOT NULL DEFAULT '',
  area        TEXT NOT NULL CHECK (area IN
              ('biblia','tecnologia','financas','casa_obra','pintura','geral')),
  modelo      TEXT,
  criada_em   TEXT NOT NULL,
  editada_em  TEXT NOT NULL,
  excluida_em TEXT
);

CREATE TABLE tags (
  id           INTEGER PRIMARY KEY,
  nome         TEXT NOT NULL UNIQUE,
  tipo         TEXT NOT NULL CHECK (tipo IN ('livre','versiculo')),
  livro        INTEGER,
  capitulo     INTEGER,
  verso_inicio INTEGER,
  verso_fim    INTEGER
);

CREATE TABLE nota_tags (
  nota_id INTEGER NOT NULL REFERENCES notas(id) ON DELETE CASCADE,
  tag_id  INTEGER NOT NULL REFERENCES tags(id)  ON DELETE CASCADE,
  origem  TEXT NOT NULL CHECK (origem IN ('manual','auto')),
  PRIMARY KEY (nota_id, tag_id)
);

CREATE INDEX idx_nota_tags_tag ON nota_tags(tag_id);
CREATE INDEX idx_tags_versiculo ON tags(livro, capitulo) WHERE tipo = 'versiculo';
CREATE INDEX idx_notas_editada ON notas(editada_em);

CREATE VIRTUAL TABLE notas_fts USING fts5(
  titulo, conteudo,
  content='notas', content_rowid='id',
  tokenize='unicode61 remove_diacritics 2'
);

CREATE TRIGGER notas_ai AFTER INSERT ON notas BEGIN
  INSERT INTO notas_fts(rowid, titulo, conteudo) VALUES (new.id, new.titulo, new.conteudo);
END;
CREATE TRIGGER notas_ad AFTER DELETE ON notas BEGIN
  INSERT INTO notas_fts(notas_fts, rowid, titulo, conteudo)
  VALUES ('delete', old.id, old.titulo, old.conteudo);
END;
CREATE TRIGGER notas_au AFTER UPDATE OF titulo, conteudo ON notas BEGIN
  INSERT INTO notas_fts(notas_fts, rowid, titulo, conteudo)
  VALUES ('delete', old.id, old.titulo, old.conteudo);
  INSERT INTO notas_fts(rowid, titulo, conteudo) VALUES (new.id, new.titulo, new.conteudo);
END;
""",
}


def agora() -> str:
    """Momento atual em UTC, ISO 8601 com microssegundos (ordena como texto)."""
    return datetime.now(timezone.utc).isoformat(timespec="microseconds")


def conectar(caminho: str | Path) -> sqlite3.Connection:
    caminho = str(caminho)
    em_memoria = caminho == ":memory:"
    if not em_memoria:
        Path(caminho).parent.mkdir(parents=True, exist_ok=True)
    con = sqlite3.connect(caminho, check_same_thread=False)
    con.row_factory = sqlite3.Row
    con.execute("PRAGMA foreign_keys = ON")
    con.execute("PRAGMA busy_timeout = 5000")
    if not em_memoria:
        con.execute("PRAGMA journal_mode = WAL")
        con.execute("PRAGMA synchronous = NORMAL")
    migrar(con)
    return con


def migrar(con: sqlite3.Connection) -> None:
    atual = con.execute("PRAGMA user_version").fetchone()[0]
    for versao in range(atual + 1, VERSAO_ESQUEMA + 1):
        con.executescript(
            f"BEGIN;\n{_MIGRACOES[versao]}\nPRAGMA user_version = {versao};\nCOMMIT;"
        )
````

````python
# "Jó" (livro 18) e "Jo" (João) ficariam iguais sem acento.
# Regra: "Jó" com acento é Jó; "Jo" sem acento é sempre João.
_SO_COM_ACENTO = {"jó": 18}


def _chave(texto: str) -> str:
    """'1 Coríntios' -> '1corintios'; 'Êx.' -> 'ex'."""
    return remover_acentos(texto).lower().replace(" ", "").replace(".", "")


def _montar_indice() -> dict[str, int]:
    indice: dict[str, int] = {}
    for livro in LIVROS:
        if livro.numero in _SO_COM_ACENTO.values():
            continue
        for forma in (livro.nome, *livro.abreviacoes):
            chave = _chave(forma)
            if indice.get(chave, livro.numero) != livro.numero:
                raise ValueError(f"abreviação repetida: {forma!r}")
            indice[chave] = livro.numero
    return indice


_INDICE = _montar_indice()


def por_numero(numero: int) -> Livro:
    return _POR_NUMERO[numero]


def buscar_livro(prefixo: str, nome: str) -> Livro | None:
    """Encontra o livro pelo prefixo numérico ('', '1', '2', '3') e pelo nome ou abreviação.

    >>> buscar_livro("1", "Co").nome
    '1 Coríntios'
    """
    nome = unicodedata.normalize("NFC", nome).lower()
    if not prefixo and nome in _SO_COM_ACENTO:
        return _POR_NUMERO[_SO_COM_ACENTO[nome]]
    numero = _INDICE.get(prefixo + _chave(nome))
    return _POR_NUMERO[numero] if numero else None
````

````python
"""Encontra referências bíblicas ("Jo 3:16", "1Co 13:4-7", "Sl 23") dentro de um texto."""

from __future__ import annotations

import re
from dataclasses import dataclass

from notepi import livros
from notepi.texto import remover_acentos

# Abreviações que também são palavras comuns em português ("os 3 pontos", "na 2ª").
# Sem versículo ("Os 6"), elas NÃO viram referência; com versículo ("Os 6:6"), viram.
PALAVRAS_COMUNS = frozenset({"os", "na", "ne", "et", "at", "am", "is", "ag", "ed"})


@dataclass(frozen=True)
class Referencia:
    livro: int
    capitulo: int
    verso_inicio: int | None = None  # None = capítulo inteiro
    verso_fim: int | None = None

    @property
    def canonica(self) -> str:
        """Forma única usada como nome da tag: 'Romanos 12:1-2', 'João 3:16', 'Salmos 23'."""
        nome = livros.por_numero(self.livro).nome
        if self.verso_inicio is None:
            return f"{nome} {self.capitulo}"
        if self.verso_fim == self.verso_inicio:
            return f"{nome} {self.capitulo}:{self.verso_inicio}"
        return f"{nome} {self.capitulo}:{self.verso_inicio}-{self.verso_fim}"


_PADRAO = re.compile(
    r"""
    (?<!\w)
    (?:(?P<num>[123])\s*|(?P<rom>I{1,3})\s+)?     # 1, 2, 3 ou I, II, III
    (?P<livro>[^\W\d_]{2,})\.?                      # nome ou abreviação (só letras)
    \s*
    (?P<cap>\d{1,3})
    (?:\s*[:.]\s*
       (?P<versos>\d{1,3}(?:\s*[-–]\s*\d{1,3})?(?:\s*,\s*\d{1,3}(?:\s*[-–]\s*\d{1,3})?)*)
    )?
    (?!\w)
    """,
    re.VERBOSE,
)
_INICIO_DE_PALAVRA = re.compile(r"(?<!\w)\w")


def _intervalos(versos: str) -> list[tuple[int, int]]:
    """'1,2,5-7' -> [(1, 2), (5, 7)]: junta versos seguidos e descarta intervalos inválidos."""
    brutos = []
    for parte in versos.replace("–", "-").split(","):
        inicio, _, fim = parte.partition("-")
        a, b = int(inicio), int(fim) if fim.strip() else int(inicio)
        if 1 <= a <= b:
            brutos.append((a, b))
    brutos.sort()
    juntos: list[tuple[int, int]] = []
    for a, b in brutos:
        if juntos and a <= juntos[-1][1] + 1:
            juntos[-1] = (juntos[-1][0], max(b, juntos[-1][1]))
        else:
            juntos.append((a, b))
    return juntos


def _interpretar(m: re.Match[str], *, permitir_ambiguas: bool) -> list[Referencia] | None:
    """None = não é uma referência (continua procurando); [] = é, mas inválida."""
    prefixo = m["num"] or (str(len(m["rom"])) if m["rom"] else "")
    livro = livros.buscar_livro(prefixo, m["livro"])
    if livro is None:
        return None
    capitulo = int(m["cap"])
    if m["versos"] is None:
        comum = remover_acentos(m["livro"]).lower() in PALAVRAS_COMUNS
        if comum and not prefixo and not permitir_ambiguas:
            return None
        if not 1 <= capitulo <= livro.capitulos:
            return []
        return [Referencia(livro.numero, capitulo)]
    if not 1 <= capitulo <= livro.capitulos:
        return []
    return [Referencia(livro.numero, capitulo, a, b) for a, b in _intervalos(m["versos"])]


def encontrar(texto: str) -> list[Referencia]:
    """Todas as referências do texto, sem repetição, na ordem em que aparecem."""
    resultado: list[Referencia] = []
    fim_ultimo = 0
    for inicio in _INICIO_DE_PALAVRA.finditer(texto):
        if inicio.start() < fim_ultimo:
            continue
        m = _PADRAO.match(texto, inicio.start())
        if not m:
            continue
        refs = _interpretar(m, permitir_ambiguas=False)
        if refs is None:
            continue
        fim_ultimo = m.end()
        for ref in refs:
            if ref not in resultado:
                resultado.append(ref)
    return resultado


def referencia_exata(texto: str) -> Referencia | None:
    """Se o texto inteiro for UMA referência ('Romanos 12', 'Rm 12:2'), devolve ela."""
    m = _PADRAO.fullmatch(texto.strip())
    if not m:
        return None
    refs = _interpretar(m, permitir_ambiguas=True)
    return refs[0] if refs and len(refs) == 1 else None
````

````python
"""Tags livres (digitadas) e de versículo (detectadas no texto ou digitadas).

As funções que alteram dados NÃO fazem commit: quem chama (notas.py) abre a transação.
"""

from __future__ import annotations

import re
import sqlite3

from notepi import versiculos
from notepi.versiculos import Referencia


def normalizar_livre(nome: str) -> str:
    """' #Pintura  Parede ' -> 'pintura parede'."""
    return re.sub(r"\s+", " ", nome.strip().lstrip("#").strip()).lower()


def separar(texto: str) -> list[str]:
    """'pintura, compra, pintura' -> ['pintura', 'compra'] (sem vazios nem repetidos)."""
    nomes: list[str] = []
    for parte in texto.split(","):
        parte = parte.strip()
        if parte and parte not in nomes:
            nomes.append(parte)
    return nomes


def _id_livre(con: sqlite3.Connection, nome: str) -> int:
    con.execute(
        "INSERT INTO tags(nome, tipo) VALUES (?, 'livre') ON CONFLICT(nome) DO NOTHING", (nome,)
    )
    return con.execute("SELECT id FROM tags WHERE nome = ?", (nome,)).fetchone()["id"]


def _id_versiculo(con: sqlite3.Connection, ref: Referencia) -> int:
    con.execute(
        """INSERT INTO tags(nome, tipo, livro, capitulo, verso_inicio, verso_fim)
           VALUES (?, 'versiculo', ?, ?, ?, ?) ON CONFLICT(nome) DO NOTHING""",
        (ref.canonica, ref.livro, ref.capitulo, ref.verso_inicio, ref.verso_fim),
    )
    return con.execute("SELECT id FROM tags WHERE nome = ?", (ref.canonica,)).fetchone()["id"]


def _id_para_nome(con: sqlite3.Connection, nome: str) -> int | None:
    ref = versiculos.referencia_exata(nome)
    if ref is not None:
        return _id_versiculo(con, ref)
    livre = normalizar_livre(nome)
    return _id_livre(con, livre) if livre else None


def definir_manuais(con: sqlite3.Connection, nota_id: int, nomes: list[str] | tuple[str, ...]) -> None:
    """Troca as tags manuais da nota por `nomes`. Um nome que é versículo vira tag de versículo."""
    con.execute("DELETE FROM nota_tags WHERE nota_id = ? AND origem = 'manual'", (nota_id,))
    for nome in nomes:
        tag_id = _id_para_nome(con, nome)
        if tag_id is None:
            continue
        con.execute(
            """INSERT INTO nota_tags(nota_id, tag_id, origem) VALUES (?, ?, 'manual')
               ON CONFLICT(nota_id, tag_id) DO UPDATE SET origem = 'manual'""",
            (nota_id, tag_id),
        )


def sincronizar_auto(con: sqlite3.Connection, nota_id: int, texto: str) -> None:
    """Recalcula as tags automáticas (versículos achados no texto). Tags manuais ficam como estão."""
    ids = [_id_versiculo(con, ref) for ref in versiculos.encontrar(texto)]
    marcas = ",".join("?" * len(ids))
    con.execute(
        f"DELETE FROM nota_tags WHERE nota_id = ? AND origem = 'auto' AND tag_id NOT IN ({marcas})",
        (nota_id, *ids),
    )
    for tag_id in ids:
        con.execute(
            """INSERT INTO nota_tags(nota_id, tag_id, origem) VALUES (?, ?, 'auto')
               ON CONFLICT(nota_id, tag_id) DO NOTHING""",
            (nota_id, tag_id),
        )


_ORDEM = "t.tipo = 'livre', t.livro, t.capitulo, t.verso_inicio, t.nome"


def da_nota(con: sqlite3.Connection, nota_id: int) -> list[sqlite3.Row]:
    """Tags da nota: versículos primeiro (em ordem bíblica), depois as livres."""
    return con.execute(
        f"""SELECT t.id, t.nome, t.tipo, nt.origem FROM tags t
            JOIN nota_tags nt ON nt.tag_id = t.id
            WHERE nt.nota_id = ? ORDER BY {_ORDEM}""",
        (nota_id,),
    ).fetchall()


def nomes_manuais(con: sqlite3.Connection, nota_id: int) -> list[str]:
    return [t["nome"] for t in da_nota(con, nota_id) if t["origem"] == "manual"]


def obter(con: sqlite3.Connection, tag_id: int) -> sqlite3.Row | None:
    return con.execute("SELECT * FROM tags WHERE id = ?", (tag_id,)).fetchone()


def listar_com_contagem(con: sqlite3.Connection) -> list[sqlite3.Row]:
    """Tags usadas por pelo menos uma nota ativa, com a quantidade de notas."""
    return con.execute(
        f"""SELECT t.*, COUNT(n.id) AS total FROM tags t
            JOIN nota_tags nt ON nt.tag_id = t.id
            JOIN notas n ON n.id = nt.nota_id AND n.excluida_em IS NULL
            GROUP BY t.id ORDER BY {_ORDEM}"""
    ).fetchall()


def remover_orfas(con: sqlite3.Connection) -> int:
    cur = con.execute("DELETE FROM tags WHERE id NOT IN (SELECT DISTINCT tag_id FROM nota_tags)")
    return cur.rowcount
````

````python
"""Criar, ler, editar, excluir (lixeira) e restaurar notas."""

from __future__ import annotations

import sqlite3
from datetime import datetime, timedelta, timezone

from notepi import modelos
from notepi import tags as tags_mod
from notepi.db import agora

AREAS = {
    "biblia": "Bíblia",
    "tecnologia": "Tecnologia",
    "financas": "Finanças",
    "casa_obra": "Casa e obra",
    "pintura": "Pintura",
    "geral": "Geral",
}

_RESUMO = "id, titulo, area, modelo, editada_em, excluida_em, substr(conteudo, 1, 160) AS inicio"


class NotaNaoEncontrada(LookupError):
    pass


class ConflitoEdicao(Exception):
    """A nota foi salva em outro aparelho depois que este formulário foi aberto."""

    def __init__(self, atual: sqlite3.Row) -> None:
        super().__init__("nota alterada em outro lugar")
        self.atual = atual


def titulo_efetivo(titulo: str, conteudo: str, momento: datetime | None = None) -> str:
    """Título digitado; se vazio, a primeira linha com texto; se nada, 'Nota de dd/mm/aaaa'."""
    if titulo.strip():
        return titulo.strip()
    for linha in conteudo.splitlines():
        limpa = linha.strip().strip("#*_ ").strip()
        if limpa:
            return limpa[:120]
    return f"Nota de {(momento or datetime.now()):%d/%m/%Y}"


def _validar(area: str, modelo: str | None) -> None:
    if area not in AREAS:
        raise ValueError(f"área inválida: {area!r}")
    if modelo is not None and modelo not in modelos.NOMES:
        raise ValueError(f"modelo inválido: {modelo!r}")


def criar(
    con: sqlite3.Connection,
    *,
    titulo: str,
    conteudo: str,
    area: str,
    modelo: str | None = None,
    tags: list[str] | tuple[str, ...] = (),
) -> int:
    _validar(area, modelo)
    momento = agora()
    titulo_final = titulo_efetivo(titulo, conteudo)
    with con:
        cur = con.execute(
            """INSERT INTO notas(titulo, conteudo, area, modelo, criada_em, editada_em)
               VALUES (?, ?, ?, ?, ?, ?)""",
            (titulo_final, conteudo, area, modelo, momento, momento),
        )
        nota_id = cur.lastrowid
        tags_mod.definir_manuais(con, nota_id, tags)
        tags_mod.sincronizar_auto(con, nota_id, f"{titulo_final}\n{conteudo}")
    return nota_id


def obter(con: sqlite3.Connection, nota_id: int, *, incluir_excluidas: bool = False) -> sqlite3.Row | None:
    sql = "SELECT * FROM notas WHERE id = ?"
    if not incluir_excluidas:
        sql += " AND excluida_em IS NULL"
    return con.execute(sql, (nota_id,)).fetchone()


def editar(
    con: sqlite3.Connection,
    nota_id: int,
    *,
    titulo: str,
    conteudo: str,
    area: str,
    tags: list[str] | tuple[str, ...],
    editada_em_base: str,
) -> None:
    """Salva a edição. `editada_em_base` é o editada_em que o formulário carregou."""
    with con:
        atual = obter(con, nota_id)
        if atual is None:
            raise NotaNaoEncontrada(nota_id)
        _validar(area, atual["modelo"])
        if atual["editada_em"] != editada_em_base:
            raise ConflitoEdicao(atual)
        titulo_final = titulo_efetivo(titulo, conteudo)
        con.execute(
            "UPDATE notas SET titulo = ?, conteudo = ?, area = ?, editada_em = ? WHERE id = ?",
            (titulo_final, conteudo, area, agora(), nota_id),
        )
        tags_mod.definir_manuais(con, nota_id, tags)
        tags_mod.sincronizar_auto(con, nota_id, f"{titulo_final}\n{conteudo}")


def excluir(con: sqlite3.Connection, nota_id: int) -> None:
    with con:
        cur = con.execute(
            "UPDATE notas SET excluida_em = ? WHERE id = ? AND excluida_em IS NULL", (agora(), nota_id)
        )
    if cur.rowcount == 0:
        raise NotaNaoEncontrada(nota_id)


def restaurar(con: sqlite3.Connection, nota_id: int) -> None:
    with con:
        cur = con.execute(
            "UPDATE notas SET excluida_em = NULL WHERE id = ? AND excluida_em IS NOT NULL", (nota_id,)
        )
    if cur.rowcount == 0:
        raise NotaNaoEncontrada(nota_id)


def recentes(con: sqlite3.Connection, *, area: str | None = None, limite: int = 30) -> list[sqlite3.Row]:
    return con.execute(
        f"""SELECT {_RESUMO} FROM notas
            WHERE excluida_em IS NULL AND (? IS NULL OR area = ?)
            ORDER BY editada_em DESC LIMIT ?""",
        (area, area, limite),
    ).fetchall()


def lixeira(con: sqlite3.Connection) -> list[sqlite3.Row]:
    return con.execute(
        f"SELECT {_RESUMO} FROM notas WHERE excluida_em IS NOT NULL ORDER BY excluida_em DESC"
    ).fetchall()


def purgar_lixeira(con: sqlite3.Connection, *, dias: int = 30, agora_: datetime | None = None) -> int:
    """Apaga de vez as notas que estão na lixeira há mais de `dias` dias. Devolve quantas."""
    limite = ((agora_ or datetime.now(timezone.utc)) - timedelta(days=dias)).isoformat(
        timespec="microseconds"
    )
    with con:
        cur = con.execute(
            "DELETE FROM notas WHERE excluida_em IS NOT NULL AND excluida_em < ?", (limite,)
        )
        tags_mod.remover_orfas(con)
    return cur.rowcount


def todas_ativas(con: sqlite3.Connection) -> list[sqlite3.Row]:
    return con.execute("SELECT * FROM notas WHERE excluida_em IS NULL ORDER BY id").fetchall()


def contar_ativas(con: sqlite3.Connection) -> int:
    return con.execute("SELECT COUNT(*) FROM notas WHERE excluida_em IS NULL").fetchone()[0]
````

````python
"""Busca por texto (FTS5) e por versículo, e 'notas relacionadas' por tags em comum."""

from __future__ import annotations

import re
import sqlite3
from dataclasses import dataclass

from markupsafe import Markup, escape

from notepi import tags as tags_mod
from notepi import versiculos
from notepi.versiculos import Referencia

# Marcadores que o snippet() do FTS5 coloca em volta das palavras encontradas.
# Usamos caracteres de controle para poder escapar o HTML antes de trocar por <mark>.
_INI, _FIM = "\x02", "\x03"

_RESUMO = "n.id, n.titulo, n.area, n.modelo, n.editada_em, substr(n.conteudo, 1, 160) AS inicio"


@dataclass(frozen=True)
class Resultado:
    id: int
    titulo: str
    area: str
    editada_em: str
    trecho: Markup


def _consulta_fts(q: str) -> str:
    """'pincel parede' -> '"pincel" "parede"*' (cada termo entre aspas; o último aceita prefixo)."""
    termos = [t for t in q.split() if re.search(r"\w", t)]
    partes = ['"' + t.replace('"', '""') + '"' for t in termos]
    if partes:
        partes[-1] += "*"
    return " ".join(partes)


def _destacar(trecho: str) -> Markup:
    return Markup(str(escape(trecho)).replace(_INI, "<mark>").replace(_FIM, "</mark>"))


def _filtros(area: str | None, modelo: str | None, tag_id: int | None) -> tuple[str, list]:
    sql, params = " AND n.excluida_em IS NULL", []
    if area:
        sql += " AND n.area = ?"
        params.append(area)
    if modelo:
        sql += " AND n.modelo = ?"
        params.append(modelo)
    if tag_id is not None:
        sql += " AND EXISTS (SELECT 1 FROM nota_tags x WHERE x.nota_id = n.id AND x.tag_id = ?)"
        params.append(tag_id)
    return sql, params


def notas_por_versiculo(
    con: sqlite3.Connection,
    ref: Referencia,
    *,
    area: str | None = None,
    modelo: str | None = None,
    tag_id: int | None = None,
) -> list[sqlite3.Row]:
    """Notas com tag de versículo no mesmo capítulo. Se `ref` tem versos, só as que cobrem esses versos
    (ou que citam o capítulo inteiro)."""
    filtro, params = _filtros(area, modelo, tag_id)
    return con.execute(
        f"""SELECT DISTINCT {_RESUMO} FROM notas n
            JOIN nota_tags nt ON nt.nota_id = n.id
            JOIN tags t ON t.id = nt.tag_id
            WHERE t.tipo = 'versiculo' AND t.livro = ? AND t.capitulo = ?
              AND (? IS NULL OR t.verso_inicio IS NULL
                   OR (t.verso_inicio <= ? AND t.verso_fim >= ?))
              {filtro}
            ORDER BY n.editada_em DESC""",
        [ref.livro, ref.capitulo, ref.verso_inicio, ref.verso_fim, ref.verso_inicio, *params],
    ).fetchall()


def buscar(
    con: sqlite3.Connection,
    q: str,
    *,
    area: str | None = None,
    modelo: str | None = None,
    tag_id: int | None = None,
    limite: int = 50,
) -> list[Resultado]:
    q = q.strip()
    filtro, params = _filtros(area, modelo, tag_id)
    if not q:
        linhas = con.execute(
            f"SELECT {_RESUMO} FROM notas n WHERE 1 = 1 {filtro} ORDER BY n.editada_em DESC LIMIT ?",
            [*params, limite],
        ).fetchall()
        return [Resultado(r["id"], r["titulo"], r["area"], r["editada_em"], escape(r["inicio"])) for r in linhas]

    resultados: list[Resultado] = []
    vistos: set[int] = set()
    ref = versiculos.referencia_exata(q)
    if ref is not None:
        marca = Markup("<mark>") + ref.canonica + Markup("</mark>")
        for r in notas_por_versiculo(con, ref, area=area, modelo=modelo, tag_id=tag_id):
            resultados.append(Resultado(r["id"], r["titulo"], r["area"], r["editada_em"], marca))
            vistos.add(r["id"])

    consulta = _consulta_fts(q)
    if consulta:
        try:
            linhas = con.execute(
                f"""SELECT n.id, n.titulo, n.area, n.editada_em,
                           snippet(notas_fts, -1, ?, ?, '…', 12) AS trecho
                    FROM notas_fts JOIN notas n ON n.id = notas_fts.rowid
                    WHERE notas_fts MATCH ? {filtro}
                    ORDER BY bm25(notas_fts) LIMIT ?""",
                [_INI, _FIM, consulta, *params, limite],
            ).fetchall()
        except sqlite3.OperationalError:
            linhas = []  # consulta que o FTS5 não entende: fica só com o que já achou
        for r in linhas:
            if r["id"] not in vistos:
                resultados.append(
                    Resultado(r["id"], r["titulo"], r["area"], r["editada_em"], _destacar(r["trecho"]))
                )
    return resultados[:limite]


def relacionadas(con: sqlite3.Connection, nota_id: int, limite: int = 10) -> list[sqlite3.Row]:
    """Outras notas ordenadas pela quantidade de tags em comum.
    Versículos contam como 'em comum' se forem do mesmo livro e capítulo."""
    return con.execute(
        """WITH minhas AS (
             SELECT t.* FROM tags t JOIN nota_tags nt ON nt.tag_id = t.id WHERE nt.nota_id = :id
           )
           SELECT n.id, n.titulo, n.area, n.editada_em, COUNT(DISTINCT m.id) AS comuns
           FROM notas n
           JOIN nota_tags nt ON nt.nota_id = n.id
           JOIN tags t ON t.id = nt.tag_id
           JOIN minhas m ON m.id = t.id
                OR (m.tipo = 'versiculo' AND t.tipo = 'versiculo'
                    AND m.livro = t.livro AND m.capitulo = t.capitulo)
           WHERE n.id != :id AND n.excluida_em IS NULL
           GROUP BY n.id
           ORDER BY comuns DESC, n.editada_em DESC
           LIMIT :limite""",
        {"id": nota_id, "limite": limite},
    ).fetchall()


def notas_da_tag(con: sqlite3.Connection, tag_id: int) -> list[sqlite3.Row]:
    """Notas de uma tag. Para tag de versículo, todas as notas do capítulo inteiro."""
    tag = tags_mod.obter(con, tag_id)
    if tag is None:
        return []
    if tag["tipo"] == "versiculo":
        return notas_por_versiculo(con, Referencia(tag["livro"], tag["capitulo"]))
    return con.execute(
        f"""SELECT {_RESUMO} FROM notas n JOIN nota_tags nt ON nt.nota_id = n.id
            WHERE nt.tag_id = ? AND n.excluida_em IS NULL ORDER BY n.editada_em DESC""",
        (tag_id,),
    ).fetchall()
````

````python
"""Backup do banco (com o app rodando), rotação de 30 dias e exportação em Markdown."""

from __future__ import annotations

import io
import re
import sqlite3
import zipfile
from datetime import date, timedelta
from pathlib import Path

from notepi import notas
from notepi import tags as tags_mod
from notepi.texto import slug

_NOME = re.compile(r"^notas-(\d{4}-\d{2}-\d{2})\.db$")


def verificar(caminho: Path) -> bool:
    """True se o arquivo é um banco SQLite íntegro."""
    con = sqlite3.connect(caminho)
    try:
        return con.execute("PRAGMA integrity_check").fetchone()[0] == "ok"
    except sqlite3.DatabaseError:
        return False
    finally:
        con.close()


def fazer_backup(con: sqlite3.Connection, destino_dir: Path, *, hoje: date | None = None) -> Path:
    """Copia o banco para destino_dir/notas-AAAA-MM-DD.db. Só fica com o nome final se estiver íntegro."""
    destino_dir = Path(destino_dir)
    destino_dir.mkdir(parents=True, exist_ok=True)
    final = destino_dir / f"notas-{(hoje or date.today()).isoformat()}.db"
    temporario = final.with_name(final.name + ".tmp")
    temporario.unlink(missing_ok=True)
    destino = sqlite3.connect(temporario)
    try:
        con.backup(destino)
    finally:
        destino.close()
    if not verificar(temporario):
        temporario.unlink(missing_ok=True)
        raise RuntimeError("o backup saiu corrompido (integrity_check falhou)")
    temporario.replace(final)
    return final


def listar(destino_dir: Path) -> list[tuple[date, Path]]:
    """Backups existentes, do mais novo para o mais antigo."""
    destino_dir = Path(destino_dir)
    if not destino_dir.is_dir():
        return []
    achados = []
    for arquivo in destino_dir.iterdir():
        m = _NOME.match(arquivo.name)
        if m:
            achados.append((date.fromisoformat(m.group(1)), arquivo))
    return sorted(achados, reverse=True)


def ultimo(destino_dir: Path) -> Path | None:
    existentes = listar(destino_dir)
    return existentes[0][1] if existentes else None


def rotacionar(destino_dir: Path, *, manter_dias: int = 30, hoje: date | None = None) -> list[Path]:
    """Apaga backups com mais de `manter_dias` dias. Devolve os apagados."""
    corte = (hoje or date.today()) - timedelta(days=manter_dias)
    apagados = []
    for dia, arquivo in listar(destino_dir):
        if dia <= corte:
            arquivo.unlink()
            apagados.append(arquivo)
    return apagados


def _aspas(texto: str) -> str:
    return '"' + texto.replace("\\", "\\\\").replace('"', '\\"') + '"'


def exportar_markdown(con: sqlite3.Connection) -> bytes:
    """Um .zip com um arquivo .md por nota ativa (cabeçalho com área, tags e datas)."""
    buffer = io.BytesIO()
    with zipfile.ZipFile(buffer, "w", zipfile.ZIP_DEFLATED) as zipado:
        for nota in notas.todas_ativas(con):
            nomes = [t["nome"] for t in tags_mod.da_nota(con, nota["id"])]
            cabecalho = [
                "---",
                f"titulo: {_aspas(nota['titulo'])}",
                f"area: {nota['area']}",
                f"modelo: {nota['modelo'] or ''}",
                "tags: [" + ", ".join(_aspas(n) for n in nomes) + "]",
                f"criada_em: {nota['criada_em']}",
                f"editada_em: {nota['editada_em']}",
                "---",
                "",
            ]
            nome_arquivo = f"{nota['id']:04d}-{slug(nota['titulo'])}.md"
            zipado.writestr(nome_arquivo, "\n".join(cabecalho) + nota["conteudo"] + "\n")
    return buffer.getvalue()
````

````python
def executar(config: Config) -> Path:

        con.close()
````

````python
        "area": area,
        "modelo": modelo,

    if nota is None:
        return _nao_encontrada(request)
    return _pagina(request, "nota_ver.html", {

        conteudo=nota["conteudo"],
        area=nota["area"],
        modelo=nota["modelo"],

           area: Campo = "geral", tags: Campo = "", editada_em_base: Campo = ""):
    area = _area_ou(area, "geral")

        notas.editar(con, nota_id, titulo=titulo, conteudo=conteudo, area=area,
                     tags=tags_mod.separar(tags), editada_em_base=editada_em_base)
    except notas.NotaNaoEncontrada:
        return _nao_encontrada(request)
    except notas.ConflitoEdicao as conflito:

            chave=f"editar-{nota_id}",
        )
        contexto["atual"] = conflito.atual
        return _pagina(request, "conflito.html", contexto, 409)
    return _ir_para(f"/notas/{nota_id}")

    except notas.NotaNaoEncontrada:
        return _nao_encontrada(request)
````

````python
@router.get("/busca")
def pagina_busca(request: Request, con: Con, q: str = "", area: str | None = None,
                 modelo: str | None = None, tag: str | None = None):
    area = area if area in notas.AREAS else None
    modelo = modelo if modelo in modelos.NOMES else None
    tag_obj = tags_mod.obter(con, int(tag)) if tag and tag.isdigit() else None
    filtrando = bool(q.strip() or area or modelo or tag_obj)
    resultados = (
        busca.buscar(con, q, area=area, modelo=modelo, tag_id=tag_obj["id"] if tag_obj else None)
        if filtrando else []
    )
    return _pagina(request, "busca.html", {
        "q": q, "area": area, "modelo": modelo, "tag": tag_obj,
        "filtrando": filtrando, "resultados": resultados,
    })


@router.get("/tags")
def pagina_tags(request: Request, con: Con):
    livres, por_livro = [], {}
    for t in tags_mod.listar_com_contagem(con):
        if t["tipo"] == "livre":
            livres.append(t)
        else:
            por_livro.setdefault(livros.por_numero(t["livro"]).nome, []).append(t)
    return _pagina(request, "tags.html", {"livres": livres, "por_livro": por_livro})


@router.get("/tags/{tag_id}")
def pagina_tag(request: Request, con: Con, tag_id: int):
    tag = tags_mod.obter(con, tag_id)
    if tag is None:
        return _pagina(request, "erro.html", {"mensagem": "Tag não encontrada."}, 404)
    if tag["tipo"] == "versiculo":
        cabecalho = f"{livros.por_numero(tag['livro']).nome} {tag['capitulo']}"
    else:
        cabecalho = tag["nome"]
    return _pagina(request, "tag.html", {
        "tag": tag, "cabecalho": cabecalho, "notas": busca.notas_da_tag(con, tag_id),
    })


@router.get("/lixeira")
def pagina_lixeira(request: Request, con: Con):
    return _pagina(request, "lixeira.html", {"notas": notas.lixeira(con)})


@router.post("/versiculos/previa")
def previa_versiculos(request: Request, titulo: Campo = "", conteudo: Campo = ""):
    refs = versiculos.encontrar(f"{titulo}\n{conteudo}")
    return _pagina(request, "partials/_previa_versiculos.html", {"refs": refs})


@router.get("/saude")
def saude(request: Request, con: Con):
    config = request.app.state.config
    banco_ok = con.execute("PRAGMA quick_check").fetchone()[0] == "ok"
    ultimo = backup.ultimo(config.backup_dir)
    livre = shutil.disk_usage(Path(config.db).resolve().parent).free
    return _pagina(request, "saude.html", {
        "banco_ok": banco_ok,
        "total_notas": notas.contar_ativas(con),
        "ultimo_backup": ultimo.name if ultimo else None,
        "livre_gb": livre / 1_000_000_000,
    }, 200 if banco_ok else 503)


@router.get("/exportar")
def exportar(con: Con):
    nome = f"notepi-{date.today().isoformat()}.zip"
    return Response(
        content=backup.exportar_markdown(con),
        media_type="application/zip",
        headers={"Content-Disposition": f'attachment; filename="{nome}"'},
    )
````

````javascript
// Guarda o que você digita no próprio aparelho (localStorage) e só apaga
// depois que o servidor confirmar que salvou. Se a conexão cair, tenta de novo.
(function () {
  "use strict";
  var form = document.getElementById("form-nota");
  if (!form) return;

  var chave = "notepi:rascunho:" + form.dataset.chaveRascunho;
  var aviso = document.getElementById("aviso-rascunho");
  var CAMPOS = ["titulo", "conteudo", "area", "tags"];
  var INTERVALO_MS = 15000;
  var tentativa = null;

  function mostrar(msg) {
    aviso.textContent = msg || "";
    aviso.hidden = !msg;
  }
  function ler() {
    try { return JSON.parse(localStorage.getItem(chave)); } catch (e) { return null; }
  }
  function gravar() {
    var dados = {};
    CAMPOS.forEach(function (n) { if (form.elements[n]) dados[n] = form.elements[n].value; });
    try { localStorage.setItem(chave, JSON.stringify(dados)); } catch (e) { /* sem espaço: segue */ }
  }
  function apagar() {
    try { localStorage.removeItem(chave); } catch (e) { /* ignora */ }
  }

  // Ao abrir: se existe rascunho diferente do que veio do servidor, restaura.
  var salvo = ler();
  if (salvo) {
    var diferente = CAMPOS.some(function (n) {
      return form.elements[n] && salvo[n] !== undefined && salvo[n] !== form.elements[n].value;
    });
    if (diferente) {
      CAMPOS.forEach(function (n) {
        if (form.elements[n] && salvo[n] !== undefined) form.elements[n].value = salvo[n];
      });
      mostrar("Rascunho restaurado deste aparelho.");
      form.elements.conteudo.dispatchEvent(new Event("input", { bubbles: true }));
    }
  }

  form.addEventListener("input", gravar);
  form.addEventListener("change", gravar);

  function agendar() {
    clearTimeout(tentativa);
    tentativa = setTimeout(enviar, INTERVALO_MS);
  }

  function enviar() {
    clearTimeout(tentativa);
    tentativa = null;
    fetch(form.action, { method: "POST", body: new FormData(form) })
      .then(function (resposta) {
        if (resposta.ok) {
          apagar();
          window.location.href = resposta.url;
          return;
        }
        if (resposta.status === 409) {
          return resposta.text().then(function (html) {
            document.open();
            document.write(html);
            document.close();
          });
        }
        mostrar("O servidor não conseguiu salvar (erro " + resposta.status +
                "). Seu texto continua guardado neste aparelho.");
      })
      .catch(function () {
        mostrar("Sem conexão: rascunho salvo neste aparelho. Vou tentar enviar de novo.");
        agendar();
      });
  }

  form.addEventListener("submit", function (ev) {
    ev.preventDefault();
    gravar();
    mostrar("Salvando…");
    enviar();
  });

  window.addEventListener("online", function () {
    if (tentativa) enviar();
  });
})();
````

`deploy/instalar.sh`:

````bash
#!/usr/bin/env bash
# Instala ou atualiza o NotePi num Raspberry Pi (Raspberry Pi OS Lite 64-bit).
# Rode a partir da pasta do projeto copiada para o Pi:
#   sudo ./deploy/instalar.sh
# Pode rodar de novo quantas vezes quiser (por exemplo, para atualizar o código).
set -euo pipefail

[ "$(id -u)" -eq 0 ] || { echo "Rode com sudo: sudo ./deploy/instalar.sh"; exit 1; }
ORIGEM="$(cd "$(dirname "$0")/.." && pwd)"

echo "==> Pacotes do sistema"
apt-get update
apt-get install -y python3-venv sqlite3 rclone rsync curl

echo "==> Usuário 'notepi' e pastas"
id notepi >/dev/null 2>&1 || useradd --system --home-dir /var/lib/notepi --create-home --shell /usr/sbin/nologin notepi
install -d -o notepi -g notepi -m 750 /var/lib/notepi
install -d -m 755 /opt/notepi /mnt/backup

echo "==> Código e dependências Python"
rsync -a --delete --exclude .git --exclude .venv --exclude 'dados*' --exclude __pycache__ "$ORIGEM/" /opt/notepi/app/
[ -d /opt/notepi/venv ] || python3 -m venv /opt/notepi/venv
/opt/notepi/venv/bin/pip install --upgrade pip
/opt/notepi/venv/bin/pip install /opt/notepi/app

echo "==> Configuração"
if [ ! -f /etc/notepi.env ]; then
  install -m 640 -o root -g notepi "$ORIGEM/deploy/notepi.env.exemplo" /etc/notepi.env
fi

echo "==> Cuidados com o cartão SD"
# 1) Logs do sistema só na memória RAM (somem ao reiniciar, mas não gastam o cartão)
install -d /etc/systemd/journald.conf.d
printf '[Journal]\nStorage=volatile\nRuntimeMaxUse=30M\n' > /etc/systemd/journald.conf.d/notepi.conf
systemctl restart systemd-journald
# 2) Swap na RAM comprimida (zram) em vez de arquivo de swap no cartão
if command -v dphys-swapfile >/dev/null 2>&1; then
  dphys-swapfile swapoff || true
  systemctl disable --now dphys-swapfile || true
fi
if dpkg -s rpi-swap >/dev/null 2>&1; then
  echo "    rpi-swap já cuida do zram neste sistema"
else
  apt-get install -y zram-tools
  printf 'ALGO=lz4\nPERCENT=50\n' > /etc/default/zramswap
  systemctl enable --now zramswap || true
fi
# 3) noatime na partição raiz (o Raspberry Pi OS normalmente já vem assim)
sed -i -E '/[[:space:]]\/[[:space:]]+ext4[[:space:]]/ { /noatime/! s/(ext4[[:space:]]+)([^[:space:]]+)/\1\2,noatime/ }' /etc/fstab

echo "==> Serviços"
install -m 644 "$ORIGEM/deploy/notepi.service" "$ORIGEM/deploy/notepi-manutencao.service" \
  "$ORIGEM/deploy/notepi-manutencao.timer" /etc/systemd/system/
systemctl daemon-reload
systemctl enable notepi.service notepi-manutencao.timer
systemctl restart notepi.service
systemctl start notepi-manutencao.timer

echo "==> Tailscale (acesso de qualquer lugar)"
command -v tailscale >/dev/null 2>&1 || curl -fsSL https://tailscale.com/install.sh | sh
tailscale status >/dev/null 2>&1 || tailscale up
tailscale serve --bg 8000

ENDERECO="$(tailscale status --json | python3 -c 'import json,sys; print(json.load(sys.stdin)["Self"]["DNSName"].rstrip("."))')"
echo
echo "Pronto! Abra no celular ou no PC (com o Tailscale ligado): https://$ENDERECO"
echo "Saúde do sistema: https://$ENDERECO/saude"
````

````markdown
## Instalar no Raspberry Pi 3B

### 1. Preparar o cartão SD
- Use um cartão de **alta durabilidade** (SanDisk High Endurance, Samsung PRO Endurance ou A1/A2 de marca), 32 GB ou mais.
- No **Raspberry Pi Imager**, grave o **Raspberry Pi OS Lite (64-bit)**. Na engrenagem de opções: defina o nome `notepi`, usuário e senha, Wi-Fi (se não usar cabo), **ative o SSH** e escolha o fuso `America/Sao_Paulo`.
- Use a **fonte oficial 5V/2,5A**. Um nobreak pequeno é recomendado.

### 2. Copiar o projeto para o Pi
No PC (PowerShell), dentro da pasta do projeto:
```powershell
scp -r . <seu-usuario>@notepi.local:~/NotePi
```

### 3. Instalar
```bash
ssh <seu-usuario>@notepi.local
cd ~/NotePi
sudo ./deploy/instalar.sh
```
O script instala tudo, liga o app e o backup diário, e configura o Tailscale. Na primeira vez ele
mostra um link para você entrar na sua conta Tailscale. No painel do Tailscale, ative **MagicDNS** e
**HTTPS Certificates**. Instale o app do Tailscale no celular e no PC, com a mesma conta.

### 4. Pendrive de backup
Formate o pendrive como ext4 (ou use vfat) e descubra o UUID com `lsblk -f`. Adicione ao `/etc/fstab`:
```
# ext4:
UUID=<uuid>  /mnt/backup  ext4  defaults,noatime,nofail  0  2
# ou vfat:
UUID=<uuid>  /mnt/backup  vfat  defaults,nofail,uid=notepi,gid=notepi,umask=077  0  0
```
Depois: `sudo mount -a`. Se for ext4, rode também `sudo chown notepi:notepi /mnt/backup`.

### 5. Cópia na nuvem (opcional, recomendado)
```bash
sudo -u notepi rclone config        # crie um remote, por exemplo "gdrive"
sudo nano /etc/notepi.env           # NOTEPI_RCLONE_DESTINO=gdrive:NotePi/backup
sudo systemctl start notepi-manutencao.service   # testa agora
```

### 6. Imagem do cartão
Com tudo funcionando, desligue (`sudo shutdown now`), coloque o cartão no PC e salve uma imagem
dele (Win32 Disk Imager, opção "Read"). Se o cartão estragar, grave essa imagem num cartão novo e
restaure o último backup (abaixo).

## Restaurar um backup
```bash
sudo systemctl stop notepi
sudo cp /mnt/backup/notas-AAAA-MM-DD.db /var/lib/notepi/notas.db
sudo rm -f /var/lib/notepi/notas.db-wal /var/lib/notepi/notas.db-shm

sudo systemctl start notepi
```

- Ver se está rodando: `systemctl status notepi`

- Rodar o backup agora: `sudo systemctl start notepi-manutencao.service`
- Desligar com segurança: `sudo shutdown now` (nunca puxe da tomada)
````
